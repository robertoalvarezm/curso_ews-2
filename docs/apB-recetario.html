Para qué sirve este apéndice

ewstools (Bury 2023) es la biblioteca de referencia en Python para EWS: hace el detrending, calcula los indicadores en ventana móvil, saca los \(\tau\) de Kendall, dibuja todo con Plotly y aplica clasificadores profundos. Instálala con pip install ewstools (y tensorflow si quieres los clasificadores).

# ---- pipeline completo con ewstools -------------------------------------
import numpy as np, pandas as pd, ewstools

serie = pd.Series(pre)                        # tu serie (índice = tiempo)
ts = ewstools.TimeSeries(data=serie, transition=len(serie))

ts.detrend(method="Gaussian", bandwidth=0.2)  # bandwidth = fracción de la serie
# ts.detrend(method="Lowess", span=0.2)       # alternativa

ts.compute_var(rolling_window=0.25)           # w = 25 % de la serie
ts.compute_auto(rolling_window=0.25, lag=1)
ts.compute_skew(rolling_window=0.25)
ts.compute_kurt(rolling_window=0.25)

# indicadores espectrales: primero el espectro, luego Smax / tipo de bifurcación
ts.compute_spectrum(rolling_window=0.25)
ts.compute_smax()                             # enrojecimiento: potencia máxima
ts.compute_spec_type()                        # pesos AIC: fold / Hopf / nulo

ts.compute_ktau()                             # llena el diccionario ts.ktau
print(ts.ktau)                                # {'variance': .., 'ac1': .., 'skew': ..}

ts.state.head()      # columnas: state, smoothing, residuals
ts.ews.head()        # columnas: variance, ac1, skew, kurtosis, ...
ts.make_plotly().show()

# ---- ventana EXPANDIBLE: ewstools no la trae, se añade en dos líneas -----
res = ts.state["residuals"].dropna()
w   = int(0.25*len(res))
var_exp = res.expanding(min_periods=w).var().dropna()
ac_exp  = res.expanding(min_periods=w).apply(lambda s: pd.Series(s).autocorr(lag=1),
                                             raw=False).dropna()

from scipy.stats import kendalltau
print("tau varianza (expandible):", round(kendalltau(var_exp.index, var_exp)[0], 3))
print("tau AC(1)   (expandible):", round(kendalltau(ac_exp.index, ac_exp)[0], 3))

# ---- barrido de sensibilidad al tamaño de ventana -----------------------
for rw in [0.1, 0.2, 0.3, 0.5]:
    t2 = ewstools.TimeSeries(data=serie, transition=len(serie))
    t2.detrend(method="Gaussian", bandwidth=0.2)
    t2.compute_var(rolling_window=rw)
    t2.compute_auto(rolling_window=rw, lag=1)
    t2.compute_ktau()
    print(rw, {k: round(v, 2) for k, v in t2.ktau.items()})

Para el caso multivariado, ewstools.MultiTimeSeries calcula covarianza y autovalor dominante en ventana móvil con la misma lógica:

mts = ewstools.MultiTimeSeries(data=df)       # df: columnas = variables
mts.detrend(method="Gaussian", bandwidth=0.2)
mts.compute_covar(rolling_window=0.25, leading_eval=True)
mts.compute_corr(rolling_window=0.25)

Y en R, EWSMethods cubre el flujo univariado y comunitario:

library(EWSmethods)
res <- uniEWS(data = cbind(tiempo, serie), metrics = c("SD", "ar1", "skew"),
              method = "rolling", winsize = 50)     # winsize en % de la serie
plot(res)

res_exp <- uniEWS(data = cbind(tiempo, serie), metrics = c("SD", "ar1"),
                  method = "expanding", burn_in = 50, threshold = 2)  # expandible
plot(res_exp)
